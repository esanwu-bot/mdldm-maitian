# 成本、工作量与风险评估

所有金额为 **API/基础设施成本估算**，不含开发服务报价；不代表已批准预算。  
价格核对日期：2026-11-20。X 价格变化频繁，采购前必须重新核对。

## 1. 平台 API 成本

| 平台 | 计费模式 | 免费额度 | 关键单价 | 本项目风险 |
|---|---|---|---|---|
| LinkedIn | API 不按次收费 | 开发层有日调用上限 | 无 | 审核周期、Standard Tier 升级、60 天 Token 再授权 |
| YouTube | 配额制 | 其他端点 10,000 units/日；上传 100 次/日 | 无 | 配额申请、公开上传审核 |
| Facebook | 免费 | BUC 速率限制 | 无 | 应用审核、企业验证、Insights 指标退役 |
| X | **按量 credits** | 新用户 $20 credits | 发帖 `$0.015`；**带 URL `$0.200`**；读取 `$0.005`；自有读取 `$0.001` | 带链接帖子成本高；无原生定时；超时重试会重复计费 |
| Reddit | 通常免费 | 速率限制 | 无 | 商业条款、subreddit 规则、无 Analytics |

### 1.1 X 月度估算（仅示例，不是承诺）

假设每月 30 天，每天 1 条帖子，另加每天 1 次自有内容读取：

| 场景 | 发帖成本 | 读取成本 | 合计/月 |
|---|---:|---:|---:|
| 全部无链接 | 30 × $0.015 = $0.45 | 30 × 30 × $0.001 = $0.90 | **$1.35** |
| 全部带链接 | 30 × $0.200 = $6.00 | $0.90 | **$6.90** |
| 一半带链接 | 15×$0.200 + 15×$0.015 = $3.23 | $0.90 | **$4.13** |

不含：媒体上传（定价页未列）、失败重试、额外读取、税费。重试按 10% 估算需再加约 10%。

**控制措施：**

1. 月度预算上限写入配置，超限停止 X 发布并告警。
2. 默认“无链接帖子 + 评论区/主页引导”，带链接帖子需审批。
3. 失败/`unknown` 不允许自动重试，避免重复计费。
4. 每周对账 X 控制台用量与本地 `publish_attempts`。

## 3. 改造工作量

估算单位：人日（1 人日 ≈ 6 小时有效工作）。范围含设计、实现、测试、文档；不含平台审核等待。

| 阶段 | 范围 | 估算 | 主要不确定性 |
|---|---|---:|---|
| P0 | 审计、API 调研、架构、OAuth、P1 计划 | 5–7 | 官方文档缺口（Reddit/Meta 指标） |
| P1 | LinkedIn Adapter、OAuth、状态机、最小工作台、测试 | 8–12 | 应用审核、Page 权限、Token 再授权 |
| P2 | YouTube + Facebook Adapter、媒体上传、异步状态 | 12–16 | YouTube 审核、Meta 指标退役、视频处理 |
| P3 | Analytics 采集/标准化、UTM、询盘归因、看板 | 12–16 | Morrishk 站点事件与 CRM 接口 |
| P4 | X + Reddit、完整工作台、审计/RBAC | 12–20 | X 成本、Reddit 规则、UI 范围 |
| 合计 | — | **49–71 人日** | 不含 20% 缓冲与审核等待 |

建议加 20% 风险缓冲：**59–85 人日**。该数字用于排期，不是报价。

## 5. 依赖与前置条件

### 5.1 平台侧

- LinkedIn：开发者账号、应用、Company Page 管理员、Community Management API 开发层。
- Google：Cloud 项目、OAuth 同意屏幕、YouTube 频道、API 启用。
- Meta：开发者账号、App、Page 管理员、企业验证、App Review。
- X：开发者账号、支付方式、预算批准。
- Reddit：账号、应用注册、目标 subreddit 版规确认。

### 5.2 Morrishk 侧

- 商品主数据 API 与 `RELEASE_APPROVED` 状态。
- Ds Bit 技术数据 API 与证据字段（页码/表格）。
- 站点 UTM 落地、`page_view`/`cta_click`/`inquiry_submit` 事件。
- CRM/销售回写 `inquiry_qualified`。
- OIDC 身份源与角色。
- 法务对平台条款、隐私政策、数据保留的确认。

## 6. 排期建议

```text
P0 审核（当前） 
  └─ 阻塞项关闭（LinkedIn 应用/Page/预算）
       └─ P1 LinkedIn PoC（8–12 人日 + 审核等待）
            └─ P1 独立审核（REAL_ACCOUNT_PASS）
                 └─ P2 YouTube/Facebook
                      └─ P3 Analytics/归因
                           └─ P4 X/Reddit/完整工作台
```

每个阶段独立分支、独立提交、独立审核；未通过不得进入下一阶段。
